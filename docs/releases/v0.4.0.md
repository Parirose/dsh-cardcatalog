# dsh-cardcatalog v0.4.0

压缩后注入「原话样本」（仍只读）。本版只读取宿主传入的当前会话事件，不写文件、不读会话文件。

- 压缩后注入原话样本（`tone`）。
- 面板显示 `toneState`，能区分已注入 / 没压缩 / 没原话 / 关闭。
- v0.3 的 nudge A/B/C 三情形回归测试保持通过。

## 1. 为什么

同一会话、同一份设定、同一套注入，按「最后一次压缩点」前后切分，统计助手正文：

| 指标 | 压缩前（29 条） | 压缩后（5 条） |
|---|---|---|
| 出现口癖类标记的比例 | **79%** | **0%** |
| 出现某种称呼的比例 | 31% | 20% |

结论：设定注入（`AGENTS.md` 那一层，实测 28 次）是每轮都在的，但它只提供**规矩**；
重建后的**起始文体**由摘要决定，而摘要的语言是分析语言。文体只能靠**原话**传递。

## 2. 改动

- 新增 `tone` 配置：开关、`turns`、`maxChars`、`header`。
- 从 `agent.session.snapshotEvents()` 中寻找最后一个 `source.kind === 'compact-checkpoint'`
  事件，取压缩点之前的最后 `turns` 组真人原话与助手正文。
- 只收 `source.kind === 'user'` 和 `assistant/message`；注入物不会进入原话样本。
- 原话逐行清洗路径，保留换行；每段按 `maxChars` 截断，并标记 `…（共 N 字）`。
- 注入为独立 `<memory-tone do-not-execute>` 段，`source.kind === 'cardcatalog-tone'`。
- 每个会话只注入一次；每个会话第一次检查写一行诊断日志。
- 面板增加只读 `toneState`，显示 `injected` / `no-checkpoint` / `no-quotes` / `disabled`。

## 3. 明确不做

- 不写文件：不 append 账本、不建缓存、不改用户任何 markdown。
- 不读磁盘上的会话文件：只用宿主传入的 `snapshotEvents()`；读不到就跳过，不猜。
- 不做摘要、不改写原话。
- 不做跨会话。
- 不改目录与 nudge 的现有行为。
