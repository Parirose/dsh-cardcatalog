# dsh-cardcatalog v0.5.1

v0.5.0 的两处收尾：tone / wall 的去重收敛成同一套 helper，并补一个 wall 三处配置同步的
回归测试。行为不变。

## 1. 去重只留一套

`checkpointKey` / `lastCheckpointIndex` 本来就是共用的；这次把“压缩点之后是否已有注入”
也收敛掉：

- 删除 `hasToneAfterCheckpoint` / `hasWallAfterCheckpoint`；
- 改成 `hasInjectionAfterCheckpoint(events, boundary, kind)`；
- tone 与 wall 只是传入不同的 `source.kind`，不再各写一份循环。

这样两套去重逻辑不会随着后续版本各自漂移。

## 2. wall 三处同步测试

新增 W8，专门盯住 `DEFAULTS.wall`、`CONFIG_KEYS` 里的 `wall`、`isBuiltInDefault('wall')`：

- 文件层配置了自定义 `wall` 时，schema 默认值不能把它盖掉；
- 漏掉 `CONFIG_KEYS` 或 `isBuiltInDefault` 中任意一处，测试都会红。

这对应“面板保存了但没生效”那类最难查的 bug。
